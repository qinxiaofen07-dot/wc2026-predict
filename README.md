# 🏆 2026世界杯冠军预测

一个可在手机/电脑上使用的世界杯预测工具。

- **`index.html`** — 移动端预测页，点击球队选中出线 → 生成专属海报 → 长按保存发抖音
- **`bracket.html`** — 桌面端完整版，含 32 强→冠军淘汰赛对阵树
- **`bracket.png`** — 1080×2800 竖版预测路径图，可单独发抖音图文

## 参与方式

1. 打开页面，点击每组你预测出线的球队（至少选 24 队）
2. 点击「生成我的预测海报」
3. 长按保存图片到相册
4. 发抖音带话题 `#2026世界杯预测`

## 数据来源

48 支球队分组与淘汰赛对阵路径基于 FIFA 官方公布（2025 年 12 月抽签结果 + 2026 年 3 月附加赛）。
